# go-core-task

Учебный проект по основам Go: 9 независимых задач, каждая в своей директории с тестами.

## Требования

- Go 1.27+
- Для команд `make` — GNU Make (на Windows доступен в Git Bash / MSYS2)

## Структура

| Директория | Тема | Описание |
|---|---|---|
| `1/` | Базовые типы | Объявление переменных разных типов (int, float64, string, bool, complex64), вывод типов, объединение значений в строку, SHA-256 хэш строки с «солью» в середине |
| `2/` | Слайсы | Генерация случайного слайса, фильтрация чётных, добавление элемента, копирование, удаление по индексу |
| `3/` | Map | Обёртка `StringIntMap` над `map[string]int`: Add, Remove, Copy, Exists, Get |
| `4/` | Разность слайсов | Дженерик-функция `GetSlicesDiff`: элементы первого слайса, которых нет во втором |
| `5/` | Пересечение слайсов | Дженерик-функция `FindIntersections`: поиск общих элементов двух слайсов без дубликатов |
| `6/` | Каналы: генератор | `RandomGenerator` — горутина-генератор случайных чисел с остановкой через канал `done` |
| `7/` | Каналы: fan-in | Дженерик-функция `Merge`: слияние N входных каналов в один через `sync.WaitGroup` |
| `8/` | Синхронизация | Собственная реализация `WaitGroup` (`Add`, `Done`, `Wait`) на мьютексе и канале-семафоре |
| `9/` | Конвейер | `CubePipeline`: канал `uint8` → канал `float64` с возведением значений в куб |

Каждая директория — отдельный `package main` с `main()` для демонстрации и файлом `*_test.go`.

## Запуск

Конкретная задача:

```bash
go run ./1
go run ./7
```

Все тесты:

```bash
go test ./...
```

## Makefile

```bash
make help      # список команд
make test      # все тесты
make cover     # тесты с покрытием
make vet       # go vet
make fmt       # проверка форматирования gofmt
make check     # fmt + vet + test
make run TASK=3  # запуск задачи N (go run ./N)
```
